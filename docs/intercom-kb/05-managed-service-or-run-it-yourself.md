# Managed service or run it yourself

The software is the product either way. The difference is who does the daily work.

## Run it yourself (software)
- You define the criteria and approve every draft.
- The platform holds the records and enforces the checks.
- You own the conversation with every reply.
- Best for teams that already have someone to run outreach day to day.

## We run it for you (managed service)
- We build and verify the lists against your criteria.
- We write the drafts, run the schedule and monitor delivery.
- You receive the replies worth your time, with the research attached.
- Best for teams that want the system without hiring to operate it.

Today the platform is operated by our team as part of the managed service. Direct software access is being rolled out. A walkthrough covers what is open now and what is next. Both paths start with a walkthrough, so the setup is right before anything sends.
