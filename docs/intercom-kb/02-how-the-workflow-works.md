# How the SlideIn workflow works

SlideIn runs the same seven stages for every campaign. Each stage can see the one before it.

1. **Configure:** your business profile, offers and ideal client profiles become the Master Playbook that every later stage reads.
2. **Discover:** finds prospects that match an ideal client profile.
3. **Research:** researches each prospect and keeps the source behind every finding.
4. **Qualify:** decides whether a prospect fits, and which of your offers to lead with. Reasons are recorded.
5. **Personalize:** writes one email per prospect from the evidence, and versions every draft. No templates.
6. **Outreach:** sends only what you have approved in the dashboard. Every run starts as a dry run. Each message is checked against sending safeguards, and if a required check fails, the message is held instead of sent.
7. **Converse:** reads each reply, tags the intent, connects it to the original conversation, and feeds opt-outs into suppression.

Nothing sends until the domain is verified, the list is clean, and you approve the campaign.
